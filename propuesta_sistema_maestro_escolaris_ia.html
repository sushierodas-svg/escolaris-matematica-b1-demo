Propuesta institucional

Sistema Maestro de Producción Escolaris IA

Uso de Codex, GitHub y prompts especializados para crear lecciones interactivas, estandarizadas y listas para Canvas LMS.

Objetivo: acelerar la producción digital sin perder control académico, calidad pedagógica ni trazabilidad técnica.

Alcance de prueba

¿Qué se está probando?

  • Generación de recursos HTML para Canvas iframe.
  • Flujo profesional con GitHub y Pull Requests.
  • Control de calidad técnico y pedagógico.
  • Escalabilidad para 24 lecciones y otras materias.

Arquitectura recomendada

Sistema por capas

No se recomienda depender de un único prompt maestro gigante. Es más seguro, escalable y controlable trabajar con cuatro capas especializadas.

Prompt Maestro Pedagógico

Define la base académica.

Prompt Maestro de Producción Digital

Convierte contenido validado en HTML.

Prompt Maestro Audiovisual

Organiza guiones, video y audio.

Prompt Maestro QA

Valida calidad antes de publicar.

Capa 1

Prompt Maestro Pedagógico

Define objetivos, secuencia, actividades, evaluación, tono, nivel educativo y estructura académica.

Su salida no es HTML. Su salida es contenido validable: claro, revisable y alineado con los criterios académicos antes de producir recursos digitales.

Capa 2

Prompt Maestro de Producción Digital

Convierte el contenido validado en recursos HTML interactivos usando Codex.

  • lectura-interactiva.html
  • practica-guiada.html
  • practica-owlaris.html
  • proyecto-final.html
  • cierre.html
Capa 3

Prompt Maestro Audiovisual

▶

Producción multimedia

Maneja videos, guiones, storyboard, podcast y piezas de apoyo.

AI

Herramientas posibles

Puede integrarse con HeyGen, Luma, Synthesia u otra herramienta audiovisual seleccionada.

Capa 4

Prompt Maestro QA

Evalúa cada entrega antes de convertirla en estándar de producción.

T

QA técnico

Botones, navegación, rutas, consola, responsividad y compatibilidad iframe.

P

QA pedagógico

Claridad, secuencia, andamiaje, retroalimentación y nivel educativo.

V

QA visual

Limpieza, consistencia institucional, legibilidad y ausencia de texto sobrepuesto.

C

Canvas LMS

Funcionamiento dentro de iframe, sin dependencias externas ni scroll horizontal.

Decisión recomendada

Recomendación final

No generar las 24 lecciones de inmediato.

Primero crear una lección modelo oficial, validarla y usarla como estándar.

El objetivo no es que la IA haga cursos, sino que acelere la producción bajo control académico.

También puedes usar las flechas del teclado.
